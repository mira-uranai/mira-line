mira-shorts-uploader

An internal tool that uploads Mira's own short videos to Mira's YouTube channel.

ミラ 星々の声を届ける恋愛占い師（YouTube）

このツールについて / About

占い師ミラが自分で制作した短い縦型動画（タロットリーディング）を、ミラ自身のYouTubeチャンネルへ、予約した時刻にショート動画としてアップロードする社内用ツールです。チャンネル運営者以外は利用しません。

This is a private tool used only by the owner of the channel above. It uploads videos that we create ourselves to our own YouTube channel at scheduled times, using the YouTube Data API (videos.insert). It does not access, collect, or share any viewer data.

しくみ / How it works

  1. 運営者が、管理用のGoogleスプレッドシートに投稿日時・動画・タイトル・説明文を書く
    The operator writes the date, video, title and description in a private Google Spreadsheet.
  2. 運営者がGoogleアカウントでログインし、アップロードの権限を許可する（最初の1回のみ）
    The operator signs in once with Google OAuth and grants upload permission.
  3. 予約時刻になると、ツールが動画をミラのチャンネルへアップロードする
    At the scheduled time, the tool uploads the video to the channel.

使用するAPI / APIs used

  • YouTube Data API v3 — videos.insert（動画のアップロード）、channels.list（接続先チャンネルの確認）
  • Scopes: youtube.upload, youtube.readonly
