mira-shorts-uploader について ／ 利用規約

本ページは、占い師ミラが運営するSNS投稿ツール「mira-shorts-uploader」の取り扱いについて定めるものです。

1. このツールについて

本ツールは、ミラ自身が制作した短い動画を、ミラ自身のYouTubeチャンネルへ予約時刻にアップロードするための社内用ツールです。運営者以外の方がログインしたり、利用したりすることはありません。

2. YouTube APIサービスの利用

本ツールはYouTube APIサービスを利用しています。利用にあたっては YouTube利用規約 および Googleプライバシーポリシー が適用されます。

3. 取得する情報と使い方

  • 運営者のYouTubeチャンネルへのアップロード権限（動画の投稿のみに使用）
  • 運営者のチャンネル名（正しいチャンネルに接続できているかの確認のみに使用）

視聴者の方の個人情報やYouTubeのデータを取得・保存・第三者へ提供することはありません。

4. 保存と削除

本ツールが保存するのは、YouTubeへ接続するための認証情報（更新用トークン）のみで、運営者の管理するサーバー内に保管します。YouTubeから取得したデータは保存しません。認証情報は、権限の取り消し、または本ツールの利用終了時に直ちに削除します。削除のご依頼は下記のお問い合わせ先から受け付け、7日以内に対応します。

5. 権限の取り消し

付与した権限は Googleアカウントの権限設定ページ からいつでも取り消せます。

Privacy Policy

This policy covers "mira-shorts-uploader", an internal tool operated by the tarot reader Mira.

The tool only uploads short videos created by Mira to Mira's own YouTube channel at scheduled times. No one other than the operator signs in or uses it.

This tool uses YouTube API Services. By using it, you agree to the YouTube Terms of Service, and the Google Privacy Policy applies.

The tool accesses only (1) permission to upload videos to the operator's channel and (2) the operator's channel name, used to confirm the connection. It does not collect, store, or share any viewer's personal data or YouTube data with third parties.

Data storage and deletion: the tool stores only the OAuth refresh token needed to connect to YouTube, on a server managed by the operator. No data retrieved from YouTube is stored. The token is deleted immediately when access is revoked or when the tool is no longer used. Deletion requests can be sent to the contact below and will be handled within 7 days.

You can revoke access at any time from the Google security settings page.
